# Справочники оборудования

Откройте этот блок, когда в карточке оборудования не хватает нужного типа, производителя или модели.

## Порядок заполнения

1. Сначала добавьте [типы оборудования](type.md): ККТ, ИБП, принтер чеков.
2. Затем добавьте [производителей](manufacturer.md): Атол, Штрих-М, Powercom.
3. После этого создайте [модели оборудования](model.md), где выбираются тип и производитель.

## Пример

Для кассы **Атол 30Ф** нужны три значения:

- тип: **ККТ**
- производитель: **Атол**
- модель: **Атол 30Ф**

После этого модель можно выбрать в карточке оборудования.
