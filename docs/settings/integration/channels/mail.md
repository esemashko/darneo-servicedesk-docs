# Email

Пример адреса страницы: `https://example.com/helpdesk/settings/mail/`

Email-интеграция создает заявки из входящих писем. В настройках выбирают почтовый ящик и правила, по которым новые заявки получают тип, приоритет и отдел.

## Список

В списке видны подключенные почтовые ящики и параметры обработки писем.

![Список email-интеграций](/darneo-servicedesk-docs/assets/screenshots/settings/integration/channels/mail/list.png){ .ds-screenshot }

Для каждого ящика показаны период разбора, приоритет, тип заявки, отдел и активность. Неактивный ящик остается в списке, но письма из него не создают новые заявки.

## Форма

В форме задают правило для почтового ящика.

![Форма email-интеграции](/darneo-servicedesk-docs/assets/screenshots/settings/integration/channels/mail/form.png){ .ds-screenshot }

Поле Email выбирает ящик, из которого нужно разбирать письма. Период ограничивает, за сколько последних дней обрабатывать входящие письма. Приоритет, тип заявки и отдел подставляются в заявки, созданные из писем этого ящика.

## Когда нужен этот раздел

Открывайте Email, когда обращения приходят на общий почтовый ящик поддержки и должны автоматически попадать в ServiceDesk как заявки.
