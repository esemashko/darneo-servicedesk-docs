# SLA

SLA помогает контролировать сроки реакции и решения заявок. В настройках SLA есть две связанные части.

1. **Графики работы** задают рабочее время, выходные и исключения.
2. **SLA правила** выбирают, для каких заявок применять график и какие сроки считать нормой.

Сначала настройте графики работы, затем создайте правила SLA для нужных отделов, типов заявок, приоритетов и компаний.
