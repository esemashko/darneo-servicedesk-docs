# Плановые заявки

Пример адреса страницы: `https://example.com/helpdesk/settings/ticket_schedule/`

Плановые заявки нужны для регулярных работ, которые должны создаваться автоматически по расписанию. Например: еженедельная проверка кассового узла, ежемесячная замена расходников или плановый осмотр оборудования.

Раздел помогает администратору описать правило: когда создавать заявку, к какой компании или объекту она относится и какие поля нужно заполнить в будущей заявке.

## Список

В списке видны правила плановых заявок. Для каждого правила показаны название, заголовок будущей заявки, повторение, контекст запуска, следующий запуск и статус.

![Список плановых заявок](/darneo-servicedesk-docs/assets/screenshots/settings/tickets/automation/ticket-schedule/list.png){ .ds-screenshot }

Контекст запуска показывает, к какой компании, клиенту, договору, объекту обслуживания или оборудованию относится правило. Когда система создаст заявку, эти данные будут подставлены в карточку заявки.

Статус можно переключить прямо из списка. Неактивное правило остается в истории, но новые заявки по нему не создаются.

## Форма сценария

В форме задают расписание и шаблон будущей заявки.

![Форма плановой заявки](/darneo-servicedesk-docs/assets/screenshots/settings/tickets/automation/ticket-schedule/form.png){ .ds-screenshot }

Основные поля формы:

- название правила
- заголовок и описание создаваемой заявки
- частота, интервал, время и дни запуска
- компания, клиент, договор, объект обслуживания и оборудование
- отдел, тип, приоритет, ответственный и наблюдатели

Пример: для проверки кассового узла можно выбрать компанию, магазин, кассу и фискальный накопитель, задать запуск по понедельникам в 09:00 и указать сервисный отдел ответственным за заявку.

## Когда нужен этот раздел

Открывайте плановые заявки, когда однотипная работа должна появляться в ServiceDesk без ручного создания заявки каждый раз. Это удобно для регулярных проверок, профилактики, обслуживания точек продаж и повторяющихся задач по договору.
