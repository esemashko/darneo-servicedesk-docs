# Справочники заявок

Справочники заявок задают базовые значения, которые сотрудники выбирают в карточке заявки. Эти значения используются в списках, фильтрах, маршрутизации и SLA.

В этом разделе находятся:

- [Типы заявок](type.md)
- [Приоритеты](priority.md)
- [Статусы](status.md)

Сначала настройте статусы и основные значения, затем используйте их в автоматизации, маршрутизации и правилах SLA.
