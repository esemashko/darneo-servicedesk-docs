# Обслуживание оборудования

Разделы обслуживания помогают заранее описать, что нужно делать с оборудованием и какие заявки система должна создавать по плану.

Если на пальцах, работа строится так:

1. **Контур обслуживания** отвечает на вопрос «что обслуживаем?». Например: фискальный накопитель, ИБП, принтер чеков.
2. **Сценарий обслуживания** отвечает на вопрос «какие заявки и когда нужны?». Например: сначала согласовать дату, потом выполнить замену, потом проверить результат.
3. **Регламент обслуживания** связывает контур и сценарий с оборудованием. Например: применять замену ФН только для касс Атол.

## Пример

Компания обслуживает онлайн-кассы. У кассы есть фискальный накопитель, который нужно менять по расписанию.

- В контурах создают значение **Фискальный накопитель**.
- В сценариях создают шаги: **Согласовать дату замены** и **Заменить ФН**.
- В регламентах создают правило **Замена ФН**: контур **Фискальный накопитель**, сценарий **Замена ФН**, применимость **ККТ / Атол / Атол 30Ф**.

После этого при планировании обслуживания оборудования пользователь выбирает регламент, а система уже понимает, какой контур обслуживается и какие заявки нужно создать.
