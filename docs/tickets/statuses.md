# Статусы

Статус показывает, на каком этапе находится заявка.

## Что описать

- какие статусы есть в интерфейсе
- кто может менять статус
- что происходит после смены статуса
- как статус влияет на список заявок
- какие статусы считаются завершенными.

## Таблица для заполнения

| Статус | Когда использовать | Что происходит дальше |
| --- | --- | --- |

| В работе | Заполнить по интерфейсу | Заполнить по процессу |
| Закрыта | Заполнить по интерфейсу | Заполнить по процессу |
