# Карточка заявки

Карточка заявки показывает всю работу по одному обращению. Здесь видны основные данные, статус, сроки, ответственные, переписка, файлы, трудозатраты и история.

![Карточка заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-overview.png){ .ds-screenshot }

## Основная часть

В основной части находится содержание обращения: тема, клиентский контекст, компания, договор, объект обслуживания, оборудование, плановое обслуживание и описание проблемы.

![Основные данные заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-main.png){ .ds-screenshot }

Если поле доступно для изменения, рядом с ним отображается действие редактирования. Если поле можно очистить, появляется действие сброса.

Дополнительные поля тоже находятся в карточке. Их состав зависит от настроек ServiceDesk. Например, можно хранить причину обращения или комментарий инженера.

## Правая панель

Правая панель показывает текущее состояние заявки и контрольные параметры.

![Правая панель заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-sidebar.png){ .ds-screenshot }

В ней обычно находятся:

- текущий статус
- дата смены статуса
- плановая дата решения
- плановое время реакции
- плановые трудозатраты
- дата регистрации
- отдел
- тип заявки
- приоритет
- признак «без ответа»
- автор
- ответственный
- наблюдатели

Если срок реакции или решения просрочен, поле выделяется цветом. Это помогает быстро увидеть проблему без ручного сравнения дат.

## Кнопки статусов

Кнопки под основными данными переводят заявку в следующий доступный статус. Набор кнопок зависит от текущего статуса, роли пользователя и настроек переходов.

При некоторых переходах система просит добавить комментарий или трудозатраты. Это нужно, чтобы в истории заявки было понятно, почему изменился статус и сколько времени заняла работа.

## Комментарии

Вкладка «Комментарии» хранит переписку по заявке.

![Комментарии в карточке заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-comments.png){ .ds-screenshot }

Комментарий может быть публичным или приватным. Публичный комментарий виден клиенту, приватный используется для внутренней работы сотрудников.

В комментариях можно прикладывать файлы и изображения. Новые комментарии учитываются в списке заявок и могут попадать в системные вкладки.

## Файлы

Вкладка «Файлы» собирает вложения из комментариев заявки.

![Файлы заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-files.png){ .ds-screenshot }

Так пользователь может быстро найти все документы и изображения без просмотра всей переписки.

## Время

Вкладка «Время» показывает трудозатраты по заявке.

![Трудозатраты заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-worktime.png){ .ds-screenshot }

Трудозатраты помогают учитывать фактическую работу сотрудников. Они могут добавляться вручную или запрашиваться при переводе заявки в определенный статус.

## Подзаявки

Если у заявки есть дочерние обращения, появляется вкладка «Подзаявки». Она нужна, когда одну большую работу нужно разделить на несколько отдельных задач.

Пример: основная заявка описывает проблему кассового узла, а подзаявки разделяют диагностику принтера чеков, замену кабеля и проверку фискального накопителя.

## История

История показывает изменения по заявке: кто изменил поле, когда это произошло и что поменялось. Эта вкладка доступна пользователям, которым разрешен просмотр истории.

История полезна при спорных ситуациях, контроле SLA и разборе того, как заявка проходила через статусы.

## Почему карточки могут отличаться

Карточка собирается с учетом прав пользователя и настроек полей. Поэтому у разных ролей могут отличаться видимые поля, кнопки статусов, приватные комментарии, история и действия редактирования.
