# Карточка заявки

Карточка заявки показывает всю информацию по обращению.

## Что описать

1. Основные данные заявки.
2. Клиент или инициатор.
3. Ответственный.
4. Статус и история изменений.
5. Комментарии.
6. Файлы.
7. Связанные объекты.

## Место для скриншотов

- верхняя часть карточки
- блок комментариев
- блок файлов
- блок действий.
