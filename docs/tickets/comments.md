# Комментарии

Комментарии фиксируют переписку и ход работы по заявке. По ним видно, что уже проверили, кто ответил клиенту и какой следующий шаг нужен.

![Комментарии в заявке](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-comments.png){ .ds-screenshot }

## Добавление комментария

Введите текст в поле сообщения и отправьте его. Если нужно, прикрепите файл или изображение.

Комментарий лучше писать так, чтобы другой сотрудник мог продолжить работу без дополнительных вопросов.

Пример: «Проверил питание кассы и кабель USB. Принтер чеков не отвечает. Следующий шаг — заменить печатающий блок».

## Публичные и приватные комментарии

Публичный комментарий предназначен для общения с клиентом. Приватный комментарий используется внутри команды поддержки.

Если пользователь работает в роли клиента, приватные комментарии ему не показываются. У сотрудника поддержки может быть доступ к обоим типам комментариев.

## Вложения в комментариях

К комментарию можно добавить файлы. Они будут видны в переписке и отдельно соберутся во вкладке [Файлы](files.md).

## Новые комментарии

Новые комментарии учитываются в списке заявок. Поэтому сотрудник может быстро увидеть обращения, где появились непрочитанные сообщения.
