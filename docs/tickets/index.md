# Заявки

Заявка - основной объект работы в ServiceDesk.

## Что пользователь делает с заявкой

- создает обращение
- ищет заявку в списке
- открывает карточку
- меняет статус
- добавляет комментарии
- прикладывает файлы
- передает заявку другому сотруднику.
