# Создание заявки

Пример адреса страницы: `https://example.com/helpdesk/tickets/create/`

Создание заявки используется, когда нужно зарегистрировать новое обращение клиента, внутреннюю задачу поддержки или работу по обслуживанию оборудования.

Форма собирается с учетом прав пользователя и настроек ServiceDesk. Поэтому у разных ролей набор полей может отличаться.

![Форма создания заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-create-form.png){ .ds-screenshot }

## Основная часть формы

В левой части формы заполняют смысл обращения:

- тему
- отдел
- тип заявки
- приоритет
- описание проблемы
- файлы и изображения

Тема нужна для короткого названия заявки в списке. Описание нужно для подробностей: что произошло, когда началось, что уже проверяли, какие признаки видит клиент.

Файлы можно приложить сразу при создании. После сохранения они попадут в карточку заявки и будут доступны в переписке и на вкладке «Файлы».

## Связанные данные

В правой части формы выбирают контекст обращения:

- компанию
- контакт
- договор
- объект обслуживания
- оборудование
- плановое обслуживание
- дополнительные поля
- ответственного
- плановую дату решения

Эти поля связаны между собой. Когда пользователь выбирает компанию, система уточняет доступных клиентов, договоры, объекты и оборудование. Если выбрать объект обслуживания, список оборудования сужается до устройств этого объекта.

Пример: клиент сообщает о проблеме с кассой в магазине. Сначала выберите компанию, затем магазин или кассовый узел, затем конкретную кассу.

## Плановое обслуживание

Поле «Плановое обслуживание» появляется, когда выбрано одно оборудование и для него есть подходящие работы по обслуживанию.

В этом поле видно регламент и краткий контекст: контур обслуживания, сценарий и связанное оборудование. Это помогает создать заявку не просто «по устройству», а по конкретной плановой работе.

Если выбрать несколько устройств, поле планового обслуживания скрывается. Так система избегает ситуации, когда один регламент случайно применили сразу к разным объектам.

## Дополнительные поля

Дополнительные поля зависят от настроек ServiceDesk. Они могут быть списком, текстом, числом, датой или датой со временем.

Если поле обязательное, заявку нельзя сохранить без значения. Например, можно сделать обязательным поле «Причина обращения», чтобы все заявки сразу попадали в понятную категорию.

## Срок и ответственный

Плановая дата решения может подставляться автоматически по правилам SLA. Пользователь может изменить срок, если у него есть право на это поле.

Ответственного можно назначить сразу при создании. Если ответственный не выбран, заявка все равно может быть создана, а распределение выполнят позже в списке или карточке.

## Сохранение заявки

После нажатия «Создать» система проверяет обязательные поля, доступ к связанным объектам и корректность выбранных значений.

Если все заполнено правильно, создается заявка и открывается ее карточка. В карточке уже будут видны выбранные компания, клиент, объект, оборудование, сроки, дополнительные поля и приложенные файлы.

Если есть ошибка, форма остается на месте и показывает, что нужно исправить.
