# Создание заявки

Страница для сценария создания новой заявки.

## Что описать

1. Где нажать создание заявки.
2. Какие поля обязательны.
3. Как выбрать клиента или компанию.
4. Как заполнить тему и описание.
5. Как прикрепить файл.
6. Как сохранить заявку.

## Место для скриншотов

- кнопка создания;
- форма новой заявки;
- пример заполненной формы;
- сообщение об успешном создании.

## Подсказки

- объяснить, какие поля нельзя оставить пустыми;
- показать, как выглядит ошибка валидации;
- указать, где потом найти созданную заявку.
