# Файлы

Файлы в заявке хранят подтверждения, фотографии, документы и другие материалы по обращению. Обычно они добавляются вместе с комментариями.

![Файлы заявки](/darneo-servicedesk-docs/assets/screenshots/interface/ticket-detail-files.png){ .ds-screenshot }

## Где смотреть файлы

Все вложения можно увидеть в переписке. Если нужно быстро найти только файлы, откройте вкладку «Файлы» в карточке заявки.

Так удобно искать акт, фото ошибки, скриншот, инструкцию или другой документ без просмотра всех сообщений.

## Как добавить файл

Откройте вкладку «Комментарии», нажмите действие прикрепления файла и отправьте комментарий. После отправки вложение появится в комментарии и во вкладке «Файлы».

## Как скачать файл

У вложения есть действие скачивания или открытия. Доступ к файлу зависит от прав пользователя на заявку и комментарий, к которому файл относится.

## Если файл не загружается

Проверьте размер файла, доступность соединения и права на добавление комментариев. Если проблема повторяется, передайте администратору название файла и заявку, в которую его пытались загрузить.
