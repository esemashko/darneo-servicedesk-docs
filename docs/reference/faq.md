# Частые вопросы

Страница для коротких ответов на частые вопросы.

## Заготовка

### Я не вижу раздел ServiceDesk

Проверить права доступа и обратиться к ответственному за настройки.

### Я не могу найти заявку

Проверить номер заявки, фильтры и доступ к заявке.

### Файл не прикрепляется

Проверить размер, тип файла и сообщение об ошибке.

### Не приходит уведомление

Проверить, есть ли новое событие по заявке и включены ли уведомления для пользователя.
