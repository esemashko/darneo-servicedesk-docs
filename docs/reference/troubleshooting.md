# Решение проблем

Страница для простых пользовательских проблем.

## Формат записи

Для каждой проблемы лучше использовать одинаковый шаблон:

1. Что пользователь видит.
2. Почему это может происходить.
3. Что можно проверить самому.
4. Когда обращаться к ответственному за настройки.

## Проблемы для заполнения

- не открывается ServiceDesk
- не создается заявка
- не сохраняется комментарий
- не загружается файл
- в списке нет нужной заявки
- не видно нужного клиента или оборудования.
