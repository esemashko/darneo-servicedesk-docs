# API и AJAX

Фронтенд обращается к backend через Bitrix AJAX:

```text
/bitrix/services/main/ajax.php?action=darneo:servicedesk.<namespace>.<method>
```

## Общая схема

1. Vue-компонент вызывает API-обертку.
2. Запрос уходит в Bitrix AJAX.
3. Контроллер принимает параметры.
4. Сервис выполняет бизнес-логику.
5. Ответ возвращается во фронтенд в JSON.

## Пример описания метода

Используйте такой шаблон для новых страниц API:

| Поле | Значение |
| --- | --- |
| Назначение | Что делает метод |
| Action | Полное имя action |
| Права | Кто может вызвать |
| Параметры | Что принимает |
| Ответ | Что возвращает |
| Ошибки | Какие ошибки возможны |

## Ошибки

Ошибки должны быть понятны пользователю и вынесены в языковые файлы backend-модуля.
