# Darneo ServiceDesk

Darneo ServiceDesk - модуль для организации работы службы поддержки в Bitrix.

Эта документация нужна, чтобы быстро понять:

- как установить модуль;
- как работать с заявками;
- как администрировать настройки;
- как устроены обновления и API.

## Для кого эта документация

| Раздел | Для кого | Что внутри |
| --- | --- | --- |
| Пользователю | Оператор, сотрудник поддержки | Работа с заявками и ежедневные сценарии |
| Администратору | Ответственный за настройки | Установка, обновления, права и параметры |
| Разработчику | Тот, кто дорабатывает модуль | Архитектура, API, структура кода |

## Схема работы

```mermaid
flowchart LR
    user[Пользователь] --> ui[Интерфейс Bitrix]
    ui --> ajax[AJAX API модуля]
    ajax --> service[Сервисный слой]
    service --> db[(База данных)]
```
