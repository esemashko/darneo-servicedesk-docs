# Darneo ServiceDesk

Это заготовка пользовательской документации.

Документация должна отвечать на простой вопрос: что нажать пользователю, чтобы выполнить свою задачу в ServiceDesk.

## Для кого

- сотрудник поддержки;
- оператор первой линии;
- руководитель группы;
- пользователь, который создает или отслеживает заявки.

## Основные разделы

| Раздел | Что описывает |
| --- | --- |
| Начало работы | Как открыть ServiceDesk и понять главный экран |
| Интерфейс | Где находятся меню, поиск, фильтры и действия |
| Заявки | Как создавать, искать и обрабатывать обращения |
| Типовые сценарии | Пошаговые инструкции для частых задач |
| Клиенты и объекты | Как смотреть связанные данные |
| Уведомления | Где пользователь видит новые события |
| Справка | Частые вопросы, ошибки и словарь терминов |

## Как заполнять дальше

На каждой странице сейчас есть каркас:

- что должен узнать пользователь;
- какие шаги нужно описать;
- где лучше добавить скриншот;
- какие вопросы проверить перед публикацией.
