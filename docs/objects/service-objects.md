# Объекты обслуживания

Пример адреса страницы: `https://example.com/helpdesk/object/`

Объект обслуживания - это место, площадка или зона, где выполняются работы. Например, магазин, кассовая зона, склад, офис или отдельный технический узел.

## Список

В списке объектов можно найти нужный объект, открыть карточку или создать новый. Объект связан с компанией, поэтому сотрудник сразу видит, к какому клиенту относится место обслуживания.

Для объектов с адресами полезно поддерживать единый формат названий. Например: `Магазин N12, кассовая зона` или `Склад, зона приемки`.

## Карточка объекта

В карточке объекта хранится наименование, адрес, компания, ответственный сотрудник, комментарий и дополнительные поля.

Есть связанные вкладки:

- «Заявки» - обращения по объекту
- «Оборудование» - устройства, которые находятся на объекте

Если оборудование распределено по объектам, сотруднику легче понять, где находится устройство и какие работы уже выполнялись на этой площадке.

![Карточка объекта обслуживания](/darneo-servicedesk-docs/assets/screenshots/objects/service-objects/card.png){ .ds-screenshot }

## Создание объекта

При создании объекта укажите понятное название, компанию и адрес. Ответственного сотрудника выбирают, если за объектом закреплен конкретный специалист.

Комментарий используйте для рабочих пояснений: как попасть на объект, где находится оборудование, какие есть ограничения по времени или доступу.

## Когда нужен этот раздел

Откройте «Объекты обслуживания», когда нужно описать место выполнения работ, найти оборудование по площадке или посмотреть заявки по конкретному адресу.
