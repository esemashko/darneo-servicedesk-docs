# Установка

## Требования

Перед установкой проверьте окружение:

- установлен Bitrix;
- доступна база данных MySQL;
- есть права администратора Bitrix;
- модуль `darneo.servicedesk` скопирован в директорию модулей.

## Установка через административный раздел

1. Откройте административный раздел Bitrix.
2. Перейдите в список модулей.
3. Найдите `darneo.servicedesk`.
4. Нажмите установку модуля.
5. Проверьте, что модуль появился в списке установленных.

## Проверка после установки

Проверьте базовый сценарий:

- раздел ServiceDesk открывается;
- список заявок загружается;
- новая заявка создается;
- права доступа применяются к пользователям.

!!! note "Для разработчика"
    Если установка проверяется локально, фиксируйте все ручные операции с базой данных в журнале проекта.
