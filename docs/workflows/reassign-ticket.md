# Передача заявки другому сотруднику

Сценарий для смены ответственного.

## Заготовка шагов

1. Откройте карточку заявки.
2. Найдите поле ответственного.
3. Выберите нового сотрудника.
4. Сохраните изменение.
5. Добавьте комментарий, почему заявка передана.

## Что проверить

- у всех ли пользователей есть право менять ответственного;
- приходит ли уведомление новому ответственному;
- остается ли история изменения в карточке.
