# Поиск нужной заявки

Сценарий нужен, когда пользователь знает часть информации по обращению и хочет быстро открыть нужную заявку. Например, известен номер заявки, клиент, тема, ответственный или статус.

## Где искать

Основная точка поиска — [список заявок](../tickets/list.md). В нем можно использовать поиск, фильтры, вкладки и колонки.

Если у команды есть разные рабочие процессы, заранее настройте [вкладки заявок](../settings/tickets/fields/ticket-tabs.md). Например, отдельные вкладки для новых обращений, заявок в работе, просроченных задач и закрытых обращений.

## Шаги

1. Откройте список заявок.
2. Выберите подходящую вкладку, если она есть.
3. Введите номер, тему, клиента или другой признак в строку поиска.
4. Уточните результат фильтрами: статус, приоритет, ответственный, клиент или период.
5. Проверьте найденные строки и откройте нужную заявку.

## Примеры поиска

Если клиент называет номер обращения, ищите по номеру. Если номер неизвестен, ищите по клиенту, теме или оборудованию. Если нужно проверить незавершенные обращения, отфильтруйте список по активным статусам.

## Что настроить заранее

- [колонки и вкладки списка](../settings/tickets/fields/ticket-tabs.md), чтобы важные поля были видны сразу
- [статусы](../settings/tickets/dictionaries/status.md), чтобы фильтры отражали реальный процесс
- [права доступа](../settings/staff/access/permission.md), если пользователи должны работать только с частью разделов
- [ограничения сотрудников](../settings/staff/access/restrictions.md), если специалистам нужно показывать только связанные с ними данные
