# Поиск нужной заявки

Сценарий для ситуации, когда пользователь знает номер, тему или клиента.

## Заготовка шагов

1. Откройте список заявок.
2. Введите номер, тему или другой признак в поиск.
3. Уточните результат фильтрами.
4. Откройте найденную заявку.
