# Обработка обращения

Базовый сценарий обработки заявки.

## Заготовка шагов

1. Открыть новую заявку.
2. Проверить описание и вложения.
3. Уточнить недостающую информацию.
4. Взять заявку в работу.
5. Добавить комментарий о выполненных действиях.
6. При необходимости передать заявку дальше.
7. Закрыть заявку после решения.

## Что уточнить при заполнении

- какие статусы используются в реальном процессе;
- кто назначает ответственного;
- когда нужно писать клиенту;
- когда заявку можно закрывать.
