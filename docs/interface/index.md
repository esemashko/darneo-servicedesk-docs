# Интерфейс

Раздел объясняет, где что находится.

## Что описать

- главное меню;
- список заявок;
- карточку заявки;
- кнопки действий;
- поиск и фильтры;
- уведомления и индикаторы.

## Правило текста

Писать через действия пользователя.

Например:

> Чтобы найти заявку, откройте список заявок и введите номер или часть темы в поле поиска.
