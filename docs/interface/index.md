# Интерфейс

Раздел описывает общие элементы, которые повторяются в разных частях ServiceDesk. Здесь собраны правила навигации, списков, вкладок, колонок, поиска и фильтров.

Если говорить просто, интерфейс работает как рабочее место диспетчера. В одном разделе пользователь выбирает нужный список, настраивает вид таблицы, находит нужную запись и открывает карточку для работы.

## Как устроен раздел

- [Навигация](navigation.md) объясняет переходы между разделами, списками и карточками
- [Списки и таблицы](lists-and-tables.md) описывают строки, колонки, сортировку, страницы и действия
- [Вкладки и колонки](tabs-and-columns.md) объясняют системные и пользовательские представления
- [Поиск и фильтры](search-and-filters.md) показывают, как сужать список до нужных записей

## Где читать про заявки

Работа с заявками вынесена в отдельный раздел [Заявки](../tickets/index.md). Там описаны список заявок, карточка заявки, комментарии, файлы и статусы.

Общие механики не дублируются в каждой статье. Например, настройка колонок описана в интерфейсе, а в статье про список заявок объясняется, какие именно данные важны для заявок.

## Права доступа

Интерфейс показывает только те разделы, поля и действия, которые доступны пользователю. Поэтому у администратора, сотрудника поддержки и клиента экран может отличаться.

Пример: сотрудник видит рабочие поля заявки и внутренние комментарии, а клиент видит только доступную ему часть обращения.
