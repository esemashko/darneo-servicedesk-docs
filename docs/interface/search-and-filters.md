# Поиск и фильтры

Страница про быстрый поиск нужных данных.

## Что описать

- поиск по номеру заявки
- поиск по теме или тексту
- фильтр по статусу
- фильтр по ответственному
- сброс фильтров.

## Пример структуры инструкции

1. Откройте список заявок.
2. Введите запрос в поле поиска.
3. При необходимости выберите фильтр.
4. Проверьте список результатов.

## Вопросы для проверки

- сохраняются ли выбранные фильтры
- видит ли пользователь только доступные ему заявки
- как отображается пустой результат.
