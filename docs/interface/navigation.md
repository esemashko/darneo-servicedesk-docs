# Навигация

Навигация помогает быстро перейти от общего списка к конкретной записи и обратно. Основной путь работы простой: открыть раздел, выбрать список, найти запись, открыть карточку.

## Разделы

Основные рабочие разделы открываются из меню ServiceDesk. Чаще всего пользователь работает с заявками, клиентами, компаниями, объектами обслуживания и оборудованием.

Настройки находятся отдельно. Они нужны администраторам, когда нужно изменить справочники, поля, вкладки, права доступа или автоматизацию.

## Списки и карточки

Большинство разделов построено одинаково.

1. В списке пользователь видит несколько записей сразу.
2. Поиск, фильтры и вкладки помогают оставить только нужные записи.
3. Клик по номеру, названию или действию открывает карточку.
4. В карточке пользователь смотрит подробности и выполняет доступные действия.

Пример: в списке заявок можно открыть обращение по номеру или теме. В карточке уже видны клиент, объект обслуживания, статус, сроки, комментарии и файлы.

## Связанные записи

Карточки связаны друг с другом ссылками. Из заявки можно перейти к клиенту, компании, договору, объекту обслуживания или оборудованию, если у пользователя есть доступ к этим данным.

Это удобно, когда нужно понять контекст обращения. Например, заявка связана с кассовым узлом, а из карточки можно открыть оборудование и проверить его данные.

## Возврат к работе

После просмотра карточки вернитесь к списку тем способом, который удобен в вашем окружении: через кнопку браузера, боковую панель Bitrix или ссылку раздела. Выбранная вкладка списка может открываться по ссылке с сохраненным якорем.
