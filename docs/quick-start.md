# Быстрый старт

Эта страница для короткого запуска без деталей.

## 1. Установить модуль

Проверьте требования и установите модуль по инструкции:

[Установка](installation.md)

## 2. Открыть ServiceDesk

В Bitrix откройте раздел модуля Darneo ServiceDesk.

## 3. Создать первую заявку

Минимальный сценарий:

1. Откройте список заявок.
2. Нажмите создание заявки.
3. Заполните клиента, тему и описание.
4. Сохраните заявку.

## 4. Проверить обработку

После создания заявки проверьте:

- заявка появилась в списке;
- у нее есть номер и статус;
- ответственный видит ее в интерфейсе;
- уведомления работают по настройкам модуля.
