# Пользователю

Этот раздел описывает ежедневную работу в ServiceDesk простым языком.

## Основные сценарии

- создать заявку;
- найти заявку;
- изменить статус;
- добавить комментарий;
- прикрепить файл;
- назначить ответственного.

## Термины

| Термин | Значение |
| --- | --- |
| Заявка | Обращение клиента или сотрудника |
| Статус | Текущее состояние заявки |
| Ответственный | Сотрудник, который ведет заявку |
| Наблюдатель | Пользователь, который следит за заявкой |
