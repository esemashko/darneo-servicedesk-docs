# Заявки

Заявка - основной рабочий объект ServiceDesk.

## Создание заявки

1. Откройте раздел заявок.
2. Нажмите создание новой заявки.
3. Укажите клиента или сотрудника.
4. Заполните тему.
5. Опишите проблему или запрос.
6. Сохраните заявку.

## Работа со статусом

Статус показывает, на каком этапе находится заявка.

Пример:

| Статус | Что означает |
| --- | --- |
| Новая | Заявку еще не взяли в работу |
| В работе | Ответственный уже занимается заявкой |
| Закрыта | Работа по заявке завершена |

## Комментарии

Комментарии нужны, чтобы фиксировать ход работы:

- что уже проверили;
- что ответил клиент;
- какие действия выполнил сотрудник.

## Файлы

К заявке можно прикладывать файлы, если это разрешено настройками модуля.
