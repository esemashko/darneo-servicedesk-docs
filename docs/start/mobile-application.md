# Заявки в мобильном приложении

Администратор один раз добавляет ServiceDesk в мобильное приложение Битрикс24. После этого сотрудники открывают заявки из меню приложения.

## Создание локального приложения

Нужен доступ администратора к разделу **Разработчикам**.

1. Откройте **Разработчикам** → **Другое**.
2. Выберите **Локальное приложение**.

## Настройка приложения

| Поле | Что указать |
| --- | --- |
| **Путь вашего обработчика** | `https://portal/mobile/darneo-helpdesk/app.php?target=/helpdesk/tickets/` |
| **Путь для первоначальной установки** | `https://portal/mobile/darneo-helpdesk/install.php` |
| **Использует только API** | Не устанавливайте флажок |
| **Поддерживает BitrixMobile** | Установите флажок |
| **Название пункта меню Russian (ru)** | Понятное сотрудникам название, например `Заявки` или `Helpdesk` |

Вместо `portal` укажите домен портала. Оба адреса должны быть доступны по HTTPS.

![Настройка локального приложения](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/local-application-settings.png){ .ds-screenshot }

В блоке **Настройка прав** выберите:

- **Встраивание приложений (placement)**
- **Пользователи (минимальный) (user_brief)**
- **Мобильное приложение (mobile)**

Нажмите **Сохранить**. Если после установки измените адреса, права или название, откройте настройки приложения и нажмите **Переустановить**.

## Где открыть заявки

Откройте **Меню** → **Маркет** и выберите пункт с названием, указанным при настройке.

![Пункт Helpdesk в меню мобильного приложения](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/helpdesk-menu-item.png){ .ds-screenshot }

## Push-уведомления

Настройка включает или отключает показ Push у текущего пользователя. Она не влияет на уведомления других сотрудников и настройки событий ServiceDesk.

В мобильном приложении откройте **Уведомления**, нажмите кнопку с тремя точками и выберите настройки уведомлений.

![Переход к настройкам уведомлений](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/notification-settings-menu.png){ .ds-screenshot }

В разделе **ServiceDesk** снимите флажок **Push-уведомления в мобильном приложении** у пункта **Уведомления по заявкам**. Чтобы включить уведомления снова, установите флажок.

![Push-уведомления по заявкам](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/ticket-push-notifications.png){ .ds-screenshot }

Чтобы уведомление пришло на телефон, проверьте:

- В [настройках каналов уведомлений](../notifications/channel-settings.md) включен Push для нужного события
- У пользователя не снят флажок **Push-уведомления в мобильном приложении**
- В настройках телефона разрешены уведомления для приложения Битрикс24
