# Работа с заявками в мобильном приложении

Эта страница поможет добавить ServiceDesk в мобильное приложение Битрикс24. Настройку один раз выполняет администратор портала. После этого сотрудники смогут открывать список заявок из меню мобильного приложения.

## Создание локального приложения

Для настройки нужен доступ администратора к разделу **Разработчикам**.

1. Откройте раздел **Разработчикам**.
2. Откройте карточку **Другое** — в ней находятся входящий вебхук, исходящий вебхук и локальное приложение.
3. В открывшейся панели выберите **Локальное приложение**.

## Настройка приложения

В форме заполните основные параметры.

| Поле | Что указать |
| --- | --- |
| **Путь вашего обработчика** | `https://portal/mobile/darneo-helpdesk/app.php?target=/helpdesk/tickets/` |
| **Путь для первоначальной установки** | `https://portal/mobile/darneo-helpdesk/install.php` |
| **Использует только API** | Не устанавливайте флажок |
| **Поддерживает BitrixMobile** | Установите флажок |
| **Название пункта меню Russian (ru)** | Понятное сотрудникам название, например `Заявки` или `Helpdesk` |

Вместо `portal` укажите домен своего портала. Оба адреса должны быть доступны по HTTPS.

Если в форме показаны поля кода и ключа приложения, оставьте их пустыми. Остальные параметры оставьте без изменений.

![Настройка локального приложения](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/local-application-settings.png){ .ds-screenshot }

В блоке **Настройка прав** выберите:

- **Встраивание приложений (placement)**
- **Пользователи (минимальный) (user_brief)**
- **Мобильное приложение (mobile)**

Нажмите **Сохранить** и дождитесь завершения установки. Если позднее измените адреса, права или название уже установленного приложения, откройте его настройки и нажмите **Переустановить**.

## Где открыть заявки

После установки пункт с выбранным названием появится в мобильном приложении Битрикс24. Откройте **Меню** → **Маркет** и выберите, например, **Helpdesk**.

![Пункт Helpdesk в меню мобильного приложения](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/helpdesk-menu-item.png){ .ds-screenshot }

## Push-уведомления у пользователя

Эта настройка действует только для текущего пользователя и его мобильного приложения. Она не отключает Push у других сотрудников и не меняет настройки событий ServiceDesk.

В мобильном приложении перейдите в окно **Уведомления**. Нажмите кнопку с тремя точками в правом верхнем углу и откройте настройки уведомлений.

![Переход к настройкам уведомлений](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/notification-settings-menu.png){ .ds-screenshot }

В разделе **ServiceDesk** снимите флажок **Push-уведомления в мобильном приложении** напротив пункта **Уведомления по заявкам**, если хотите отключить уведомления только для этого пользователя. Чтобы включить их снова, установите флажок.

![Push-уведомления по заявкам](/darneo-servicedesk-docs/assets/screenshots/start/mobile-application/ticket-push-notifications.png){ .ds-screenshot }

Эта настройка управляет показом уведомлений у текущего пользователя и не меняет события, которые отправляет ServiceDesk. Чтобы сообщение пришло на его телефон, проверьте оба условия:

1. В [настройках каналов уведомлений](../notifications/channel-settings.md) включен Push для нужного события.
2. У пользователя не снят флажок **Push-уведомления в мобильном приложении**.

Если уведомления Битрикс24 отключены в настройках самого телефона, разрешите их и там.

## Когда нужна эта настройка

Настройте локальное приложение, если сотрудники должны работать с заявками вне компьютера: принимать обращения, следить за изменениями и быстро реагировать на новые задачи.
