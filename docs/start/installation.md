# Установка решения

Эта страница помогает выбрать способ установки ServiceDesk для Битрикс24. Решение устанавливается на коробочную версию Битрикс24.

Есть два варианта: заказать демо-установку у техподдержки Darneo или установить решение самостоятельно, если лицензионный ключ уже есть.

## Демо на 14 дней

Демо-решение устанавливают удаленно сотрудники техподдержки Darneo. Демо работает 14 дней без функциональных ограничений.

!!! warning "Важно"

    Демо устанавливается только на коробочную версию Битрикс24 с активной коммерческой лицензией. Для NFR-лицензии и демо-лицензии Битрикс24 демо-установка не выполняется.

Для установки используется [AnyDesk](https://anydesk.com/ru){ target="_blank" rel="noopener noreferrer" }. Это программа для удаленного подключения: сотрудник техподдержки подключается к вашему рабочему месту и выполняет установку вместе с вами.

Перед установкой сотрудник техподдержки проверяет, что сайт работает на коробочной версии Битрикс24 с активной коммерческой лицензией, сверяет версии PHP и MySQL, а также уточняет, не тестировалось ли решение на этом портале ранее. Повторная установка демо невозможна.

Чтобы заказать демо-установку:

1. Подготовьте доступ через AnyDesk.
2. Напишите на [support@darneo.ru](mailto:support@darneo.ru), что нужна демо-установка ServiceDesk для Битрикс24.
3. Укажите контактное лицо и удобный способ связи.
4. Дождитесь подтверждения от техподдержки.

Установка проводится по будням в 18:00 по МСК. Укажите в письме, что готовы к подключению в это время.

Пример: компания хочет проверить ServiceDesk для Битрикс24 на своем портале перед покупкой. Администратор пишет на `support@darneo.ru`, получает подтверждение времени, запускает AnyDesk и передает доступ сотруднику Darneo.

## Если лицензионный ключ уже есть

Если у вас уже есть лицензионный ключ, установку можно выполнить штатными средствами 1С-Битрикс.

Для самостоятельной установки нужен доступ в административную часть сайта и права администратора.

1. Откройте административную часть сайта.
2. Перейдите на страницу установки решений Marketplace: `/bitrix/admin/update_system_market.php?lang=ru`.
3. Найдите ServiceDesk для Битрикс24 и установите решение.
4. Откройте страницу партнерских модулей: `/bitrix/admin/partner_modules.php?lang=ru`.
5. Найдите модуль `HelpDesk` и нажмите **Установить**, если модуль еще не установлен.
6. Откройте список мастеров: `/bitrix/admin/wizard_list.php?lang=ru`.
7. В списке мастеров найдите мастер `HelpDesk` и запустите установку.

В списке мастеров выберите:

- `darneo:darneo_servicedesk` для основного портала
- `darneo:darneo_servicedesk_extranet` для экстранета

После завершения мастера проверьте, что раздел **Заявки** появился в меню и открывается для пользователей с нужными правами.

## Когда обращаться в техподдержку

Напишите на [support@darneo.ru](mailto:support@darneo.ru), если установка не запускается, решение не находится в Marketplace, мастер завершился с ошибкой или раздел **Заявки** не появился после установки.
