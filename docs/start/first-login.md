# Первый вход

Страница для пользователя, который впервые открывает раздел **Заявки** после установки решения.

## Где открыть

На локальном стенде решение доступно по адресу `http://127.0.0.1:8080/helpdesk/tickets/`.

В рабочем портале адрес будет зависеть от домена сайта, но путь остается тем же: `/helpdesk/tickets/`.

## Что открывается

По умолчанию открывается список заявок. Это основной экран, с которого пользователь начинает работу: видит заявки, статусы, приоритеты, клиентов, ответственных и сроки.

![Список заявок после первого входа](/darneo-servicedesk-docs/assets/screenshots/start/first-login/ticket-list.png){ .ds-screenshot }

## Если раздел не открывается

Проверьте, что мастер установки завершился без ошибок и в меню появился раздел **Заявки**. Если раздел не отображается или открывается ошибка доступа, обратитесь к администратору портала: пользователю могут быть не назначены права на работу с заявками.
