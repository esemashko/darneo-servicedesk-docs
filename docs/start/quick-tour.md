# Быстрый маршрут

Короткая инструкция: как выполнить базовый сценарий без подробностей.

## Сценарий

1. Открыть ServiceDesk.
2. Перейти в список заявок.
3. Найти нужную заявку или создать новую.
4. Открыть карточку заявки.
5. Добавить комментарий или изменить статус.
6. Проверить результат в списке.
