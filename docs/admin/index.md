# Администратору

Этот раздел для настройки и сопровождения модуля.

## Что обычно настраивает администратор

- права пользователей;
- статусы заявок;
- поля и списки;
- уведомления;
- обновления модуля.

## Перед изменениями

Перед изменением настроек проверьте:

1. кто будет пользоваться функцией;
2. какие права нужны;
3. как проверить результат;
4. можно ли откатить изменение.
