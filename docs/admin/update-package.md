# Пакеты обновлений

Пакет обновления содержит только файлы текущей поставки.

## Основное правило

В пакет кладем только то, что изменилось в текущей задаче и должно попасть клиенту.

Нельзя копировать предыдущие обновления целиком.

## Что не добавлять

В update-пакет нельзя добавлять:

- тесты;
- `.DS_Store`;
- `__MACOSX`;
- архивы `*.zip` в git.

## Проверка перед поставкой

Перед передачей пакета проверьте:

1. внутри нет лишних файлов;
2. структура соответствует модулю;
3. архив собран только как локальный артефакт;
4. в git попали только исходники пакета, без zip-архива.
